# はこ あそび 仕様（hako-asobi）
感覚遊具（『認知発達治療の実践マニュアル』写真3、5-2(2)「感覚遊具の操作を教える」）を画面で練習する単一HTMLアプリ。te-asobiから独立。
## 構成
- public/index.html + wrangler.jsonc（name hako-asobi）。GitHub: hos-arch/hako-asobi（ユーザーが作成予定）
## 部品（カード＝窓＋操作部）
- おす：ボタン→窓から絵がぴょん＋星
- すべらせる：つまみ→窓の丸の位置と色、音階（8音）
- まわす：ダイヤル、30°ごとにカチ、窓の花が回る
- たおす：スイッチ→窓の明かり
- もちあげる：ふたを上へ引く→窓に絵（手助け大＝タップで保持）
- はじく：円盤をはじく→慣性で回り、窓の絵が流れる
- 絵は te-asobi と同じ初期認知の日用品5つ（くるま・りんご・バナナ・さかな・おはな）
## 段階
- 部品の数 1/3/6（1＝おす、3＝おす・すべらせる・まわす、6＝ぜんぶ）。縦横で並べ方が変わる
## 支援者メニュー（右上の点を1.2秒長押し）
- 部品の数／手助け（大＝カード全体が反応、小＝部品上のみ）／くわしく：触れ方・見た目・音／もとにもどす
## 約束
- 子ども画面に文字なし。点滅なし。音はやわらかく音量上限。名前・記録・録音・顔を保存しない。治療効果をうたわない。
